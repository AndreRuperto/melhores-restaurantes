# A Carta

Os 100 melhores restaurantes do mundo em 2026, segundo The 50 Best Restaurants: mapa, ranking, recortes por continente, país e Brasil, e uma página por restaurante (`/restaurante/:slug`).

Dados em `src/data/restaurants.js`.

## Rodar

```bash
npm install
npm run dev
```

## Railway

Build: `npm run build` · Start: `npm start` (serve `dist/` na porta `$PORT`, com fallback de SPA para as rotas).
