## Próximos passos
Para os **24 casos pendentes**, solicitar autorização aos restaurantes ou fotógrafos e pesquisar mais fotos originais licenciadas. Não utilizar como substitutas fotos do bairro, entradas de antigas unidades, nomes semelhantes, logotipos ou fotografias do Google Maps/Tripadvisor/Instagram sem autorização.

**Validações pendentes:** `npm run check:profiles`, `npm run build` e conferência de carregamento/visual no navegador.
