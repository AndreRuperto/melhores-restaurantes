# Fontes locais

Mesmas famílias da identidade original, distribuídas sob SIL Open Font License (licenças ao lado).
Arquivos Latin e Latin Extended, normal e itálico. Origem: pacotes @fontsource-variable/cormorant-garamond e @fontsource-variable/source-serif-4 fixados no package-lock.json.
Para atualizar os arquivos com as versões instaladas: python scripts/qa/vendor-fonts.py.
